# 🤖 AI-FAQ: Multitasking Bot

Это технический документ для ИИ-ассистента, помогающего в разработке и поддержке бота Multitasking.

## 📌 Основной функционал
Бот предназначен для управления сообществом в Discord (семья в GTA5RP), автоматизации сборов, управления заявками, экономикой и приватными каналами.

## 📂 Архитектура проекта
- `main.py`: Основной файл. Содержит всю логику, команды, обработчики событий и UI-компоненты.
- `data.json`, `points.json`, `chips.json`, `roulette.json`: Хранилища данных в формате JSON.

## ⚙️ Ключевые системы
1. **Сборы (!vzp, !vzh, !list):**
   - Создают сообщение с кнопками-слотами или одной кнопкой записи.
   - Создают отдельный тред для живого списка участников.
   - Поддерживают резерв, время сбора и закрытие списка.
   - В треде сбора можно занять/освободить слот, просто написав его номер (альтернатива кнопкам).
   - `!vzh` хранит не только `event_time` (строка ЧЧ:ММ для отображения), но и `event_datetime` (точный ISO-datetime), вычисленный через `next_vzh_datetime()` по хардкод-расписанию `VZH_FACTION_WEEKDAYS` (банды/мафии, настраивается в панели настроек через `vzh_schedule_settings`). Без этого поля (старые сборы) `vzh_reminder_loop` откатывается на прежнюю эвристику "сегодня/завтра" по `created_at`.
2. **Тикет-система:**
   - Модальное окно подачи заявки $\rightarrow$ Создание канала $\rightarrow$ Рассмотрение (Одобрить/Отклонить) $\rightarrow$ Приглашение на обзвон.
3. **Экономика (Алмазы 💎 и Фишки 🎰):**
   - Начисление за активность в войсе.
   - Магазин товаров с автоматической выдачей ролей или уведомлением менеджера.
   - Обмен алмазов на фишки 1:1.
4. **Приватные комнаты:**
   - Триггер-канал $\rightarrow$ Автоматическое создание личного канала с панелью управления.
5. **Интерактивные настройки (`/панель_настройки`):**
   - Многоуровневое меню (Select $\rightarrow$ Embed $\rightarrow$ Modals/Pickers) для конфигурации всех аспектов бота без использования консоли.
   - Категории разбиты на 2 страницы (кнопки "Страница вперёд/назад"), чтобы список не был перегружен.
6. **Кабинет рекрута (`/кабинет_рекрута`):**
   - Панель для тикет-менеджеров: статистика по одобренным/отклонённым заявкам (`recruit_stats`).
   - Выдача варна доступна только тикет-менеджерам и снимается исключительно за деньги (в отличие от moriarty-helper, где есть вариант "баллы/деньги").
   - Лог выдачи варна — отдельный канал (`/канал_варнов`), сообщение лога удаляется при снятии варна.

## 🛠 Технические особенности
- **Discord.py:** Используются `app_commands` (слэши) и `commands.Bot` (префиксы).
- **Хранение:** Данные хранятся в глобальных словарях и синхронизируются с JSON-файлами через `save_data()`.
- **Время:** Все временные метки работают по МСК (UTC+3).

## ⚠️ Важные правила при правках
- **Сохранение данных:** При любом изменении настроек или БД обязательно вызывать `save_data()`.
- **Стиль:** Использовать `discord.Embed` для всех ответов. Футер всегда `DIAMOND`.
- **Права:** Проверять права администратора через `is_admin()` или `is_admin_ctx()`.
